Политика конфиденциальности Waysplit

Обновлено 14 ноября 2026 г. Относится к расширению Chrome Waysplit и к программе-компаньону для Windows, она называется waysplit-host.

Waysplit это VPN только для браузера Chrome через серверы, которые добавляете вы сами. Разработчик Waysplit не получает никаких ваших данных. У Waysplit нет своего сервера, учётных записей, аналитики, рекламы и телеметрии. Всё, что вы вводите, остаётся на вашем компьютере. По сети уходит только то, что нужно для работы. Все такие запросы перечислены ниже.

Что хранится и где

Всё хранится только на вашем компьютере.

В хранилище расширения в Chrome лежат:

  • серверы: ссылки vless:// и hysteria2:// со всеми параметрами, включая ключи и пароли;
  • адреса подписок и то, что пришло с ними: трафик, срок и сообщение провайдера;
  • правила для сайтов вместе с их доменами сайта. О доменах сайта написано в разделе "Что расширение видит в браузере";
  • настройки.

Журнал событий для диагностики хранится только до закрытия браузера.

В папке компаньона %LOCALAPPDATA%\Waysplit лежат:

  • файлы настроек ядер sing-box и Xray. В них есть данные серверов;
  • журналы работы. Ключи, пароли и адреса подписок в них скрыты;
  • идентификатор устройства. О нём написано ниже.

Резервную копию вы делаете сами: на вкладке "Настройки", в разделе "Резервная копия", кнопкой "Сохранить копию". В копии есть ссылки серверов с ключами. Храните её как пароль.

Какие сетевые запросы делает Waysplit

  1. Ваши VPN-серверы. Сайты, которые по вашим настройкам идут через VPN, Chrome открывает через выбранный вами сервер.
  2. Ваши подписки. Компаньон скачивает список серверов по адресу подписки. Это происходит, когда вы добавляете подписку, когда нажимаете "Обновить" и по расписанию из настроек. В запросе есть заголовок User-Agent из настроек. По умолчанию это v2rayN/7.0: с ним панели подписок отдают список серверов, а не веб-страницу. Если напрямую подписка не скачалась, а VPN включён, запрос повторяется через текущий сервер.
  3. Проверка связи с сервером, или пинг. Это запрос к https://www.gstatic.com/generate_204 через проверяемый сервер. Этот адрес Google нужен для проверки соединения. Запрос уходит, когда вы нажимаете "Пинг", и для текущего сервера, когда открыто окно расширения.
  4. Кнопка "Мой IP сейчас" в диагностике. Только когда вы её нажимаете, уходит запрос к https://api.ipify.org через текущий сервер. Он показывает, какой IP-адрес видят сайты.

Запросы 3 и 4 не содержат никаких сведений о вас. Их адресаты видят только IP-адрес вашего VPN-сервера. Что делают со своими данными ваш VPN-провайдер и провайдер подписки, определяют их правила.

Идентификатор устройства

Некоторые провайдеры подписок выдают серверы, только если программа назовёт своё устройство. Так они ограничивают число устройств на подписку. Для этого у Waysplit есть идентификатор устройства:

  • это случайный номер, не связанный с оборудованием компьютера. Это не серийный номер, не MAC-адрес и не номер установки Windows;
  • он хранится только на этом компьютере, в файле %LOCALAPPDATA%\Waysplit\device-id;
  • он отправляется только провайдеру подписки и только если провайдер его требует. Сначала подписка запрашивается без идентификатора. С ним запрос повторяется, только если без него провайдер серверов не даёт. Такая подписка помечается в настройках как привязанная к устройству и дальше обновляется с идентификатором;
  • он отправляется только по защищённому соединению https://.

Вместе с идентификатором провайдер получает название системы, её версию и модель устройства. Это Windows, версия 10 или 11 и модель "Chrome". Так устройство понятно называется в списке устройств у провайдера. Удалить идентификатор можно двумя способами: ответить "да" на вопрос Удалить.cmd или удалить сам файл. Об Удалить.cmd написано ниже. Учтите, что без идентификатора при повторной установке провайдер посчитает компьютер новым устройством. Отвязать устройство от подписки можно в личном кабинете провайдера.

Что расширение видит в браузере

  • Адрес открытой вкладки. Расширение видит только её домен и только когда вы открываете окно Waysplit. Для этого есть разрешение activeTab. Домен нужен, чтобы показать, идёт ли этот сайт через VPN, и дать добавить для него правило.
  • К каким доменам обращаются вкладки. Это расширение видит только после вашего разрешения. Это необязательные разрешения webRequest и доступ к сайтам. Waysplit спрашивает их один раз: карточкой с объяснением в своём окне или когда вы первый раз нажимаете "Домены этой вкладки". Без разрешения всё остальное работает. Расширение смотрит только имена доменов в запросах вкладок. Адреса страниц и содержимое оно не смотрит. В запросах оно ничего не меняет и не блокирует. Эти имена нужны для двух вещей.

    Домены сайта. Видео, картинки и скрипты сайта часто лежат на других доменах. Допустим, для сайта есть ваше правило "через VPN" и он открыт во вкладке. Тогда Waysplit добавляет к этому правилу домены, к которым обращается эта вкладка. Иначе через VPN шла бы только сама страница. Эти домены сохраняются в хранилище расширения как часть правила. Они остаются там, пока вы не уберёте их или не удалите правило. Убрать их можно в меню "⋯" правила, в пункте "Домены сайта". Они попадают в файл правил и в резервную копию, которые вы сохраняете сами. Запоминаются только домены вкладок с сайтами из ваших правил "через VPN". Общие сервисы не добавляются: поиск, счётчики, реклама, библиотеки скриптов. Российские сайты тоже не добавляются. Из вкладок в режиме инкогнито домены к правилам не добавляются, даже если вы разрешили расширению там работать. От таких вкладок в хранилище расширения ничего не остаётся. Автоматическое добавление выключается в настройках галочкой "Автоматически добавлять домены сайта".

    Домены этой вкладки. По кнопке расширение показывает, к каким доменам обращалась вкладка. Так вы сами добавите нужные домены в правила. У каждой вкладки свой список, в нём не больше 300 доменов. На новой странице список начинается заново. Хранится он только в памяти браузера до его закрытия.

    Всё это остаётся на вашем компьютере и никуда не отправляется. Разрешение можно отозвать в настройках Chrome: откройте сведения о расширении, потом раздел доступа к сайтам.

  • Значки сайтов. Для них есть разрешение favicon. Значки видны у правил и у открытого сайта в окне Waysplit. Они берутся только из памяти самого Chrome, то есть только для сайтов, которые вы уже открывали. Waysplit не делает за ними запросов в интернет и не обращается к сторонним сервисам. Поэтому список ваших правил никуда не уходит. Если значка нет, показывается первая буква домена.
  • Настройки прокси и WebRTC в Chrome. Для них есть разрешения proxy и privacy. Они нужны, чтобы направлять сайты через VPN и чтобы WebRTC не выдавал ваш настоящий IP-адрес.

Адреса страниц и история браузера, содержимое страниц, вводимые данные и всё остальное не собираются и никуда не передаются.

Передача данных

Разработчик данные не получает, поэтому ничего не продаёт и никому не передаёт. Данные не используются для рекламы и не передаются брокерам данных. Их не читают люди. Использование данных в Waysplit соответствует правилам Chrome Web Store User Data Policy, включая требования Limited Use.

Как всё удалить

  1. Удалите расширение в Chrome. Для этого нажмите на значок Waysplit правой кнопкой и выберите "Удалить из Chrome". Вместе с расширением удалятся серверы, подписки, правила и настройки.
  2. Запустите Удалить.cmd из архива компаньона или из папки %LOCALAPPDATA%\Programs\Waysplit. Он снимет регистрацию компаньона в Chrome и удалит папку программы %LOCALAPPDATA%\Programs\Waysplit. Ещё он удалит данные в %LOCALAPPDATA%\Waysplit: журналы и настройки ядер. Идентификатор устройства он удалит, только если на его вопрос ответить "да". По умолчанию идентификатор остаётся, чтобы при повторной установке провайдер не посчитал компьютер новым устройством.
  3. Резервные копии, которые вы сохраняли сами, удалите вручную.

Изменения и связь

Waysplit privacy policy

Last updated: November 14, 2026. Applies to the Waysplit Chrome extension and to its Windows companion program, waysplit-host.

Waysplit is a browser-only VPN for Chrome that uses servers you add yourself. The Waysplit developer does not receive any of your data. Waysplit has no server of its own, no accounts, no analytics, no ads and no telemetry. Everything you enter stays on your computer. The only network requests are the ones it needs to work. They are all listed below.

What is stored and where

Everything is stored only on your computer.

Chrome's extension storage holds:

  • servers: vless:// and hysteria2:// links with all their parameters, including keys and passwords;
  • subscription URLs and what came with them: traffic, expiry date and the provider's message;
  • site rules together with their site domains. Site domains are described in "What the extension sees in the browser";
  • settings.

The diagnostic event log is kept only until the browser is closed.

The companion folder %LOCALAPPDATA%\Waysplit holds:

  • configuration files for the sing-box and Xray cores. They contain server details;
  • operation logs. Keys, passwords and subscription URLs are masked in them;
  • the device identifier, described below.

Only you make a backup: on the "Настройки" tab, in the "Резервная копия" section, with the "Сохранить копию" button. In English these are Settings, Backup and Save copy. The backup contains server links with keys. Keep it like a password.

Network requests Waysplit makes

  1. Your VPN servers. Chrome opens the sites that your settings send through the VPN via the server you selected.
  2. Your subscriptions. The companion downloads the server list from the subscription URL. It does so when you add the subscription, when you press "Обновить", which means Update, and on the schedule set in the settings. The request carries the User-Agent header from the settings. By default it is v2rayN/7.0: with it, subscription panels return a server list instead of a web page. If the direct download fails while the VPN is on, the request is repeated through the current server.
  3. Server connectivity check, or ping. This is a request to https://www.gstatic.com/generate_204 through the server being checked. Google provides this address for connectivity checks. The request is sent when you press "Пинг", which means Ping, and for the current server while the extension window is open.
  4. The "Мой IP сейчас" button in diagnostics, which means My IP now. A request to https://api.ipify.org through the current server is sent only when you press it. It shows which IP address websites see.

Requests 3 and 4 carry no information about you. Their recipients see only the IP address of your VPN server. What your VPN provider and subscription provider do with their data is governed by their own policies.

Device identifier

Some subscription providers hand out servers only if the app identifies its device. This is how they limit the number of devices per subscription. For this, Waysplit has a device identifier:

  • it is a random number not tied to the computer's hardware. It is not a serial number, not a MAC address and not the Windows installation ID;
  • it is stored only on this computer, in the file %LOCALAPPDATA%\Waysplit\device-id;
  • it is sent only to the subscription provider and only if the provider requires it. The subscription is first requested without it. The request is repeated with it only if the provider returns no servers without it. Such a subscription is marked in the settings as bound to the device and is then updated with the identifier;
  • it is sent only over a secure connection, https://.

Together with it, the provider receives the operating system name, its version and the device model. These are Windows, version 10 or 11, and the model "Chrome". This way the device is easy to recognize in the provider's device list. There are two ways to delete the identifier. You can answer "да", which means yes, when Удалить.cmd asks about it. This uninstaller is described below. Or you can delete the file itself. Note that without the identifier the provider will count the computer as a new device after a reinstall. To unbind the device from a subscription, use the provider's account page.

What the extension sees in the browser

  • The address of the open tab. The extension sees only its domain and only when you open the Waysplit window. This uses the activeTab permission. The domain is needed to show whether this site goes through the VPN and to let you add a rule for it.
  • Which domains the tabs contact. The extension sees this only after you grant permission. These are the optional webRequest and site access permissions. Waysplit asks for them once: with an explanation card in its own window, or the first time you press "Домены этой вкладки", which means Domains of this tab. Everything else works without the permission. The extension only looks at the domain names in the tabs' requests. It does not look at page addresses or content. It never modifies or blocks requests. These names are used for two things.

    Site domains, "Домены сайта" in the extension. A site's video, images and scripts are often served from other domains. Suppose you have a "through VPN" rule for a site and the site is open in a tab. Then Waysplit adds the domains that this tab contacts to that rule. Otherwise only the page itself would go through the VPN. These domains are saved in the extension storage as part of the rule. They stay there until you remove them or delete the rule. You can remove them in the rule's "⋯" menu, under "Домены сайта". They are included in the rules file and the backup that you save yourself. Only domains from tabs showing sites that have your "through VPN" rules are remembered. Common services are not added: search, analytics, ads and script libraries. Russian sites are not added either. Domains from incognito tabs are never added to rules, even if you have allowed the extension to run in incognito. Nothing from such tabs is left in the extension storage. Automatic adding can be turned off in the settings with the "Автоматически добавлять домены сайта" checkbox, which means Add site domains automatically.

    Domains of this tab, "Домены этой вкладки" in the extension. On request, the extension shows which domains a tab has contacted, so that you can add the ones you need to rules yourself. Each tab has its own list of at most 300 domains. The list starts over on a new page. It is kept only in browser memory until the browser is closed.

    All of this stays on your computer and is not sent anywhere. You can revoke the permission in Chrome's settings: open the extension's details, then Site access.

  • Website icons. They use the favicon permission. Icons are shown next to your site rules and the open site in the Waysplit window. They are read only from Chrome's own local cache, so only for sites you have already visited. Waysplit makes no network requests for them and uses no third-party services. So your list of rules never leaves the computer. If there is no icon, the first letter of the domain is shown.
  • Chrome proxy and WebRTC settings. They use the proxy and privacy permissions. They are needed to route sites through the VPN and to keep WebRTC from exposing your real IP address.

Page addresses and browsing history, page content, form input and anything else are not collected and are not transmitted anywhere.

Sharing

The developer receives no data, so nothing is sold or shared with anyone. Data is not used for advertising and is not transferred to data brokers. It is not read by humans. Waysplit's use of data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

How to delete everything

  1. Remove the extension in Chrome. Right-click the Waysplit icon and choose "Remove from Chrome". Servers, subscriptions, rules and settings are deleted with it.
  2. Run Удалить.cmd, the uninstaller, from the companion archive or from %LOCALAPPDATA%\Programs\Waysplit. It unregisters the companion from Chrome and deletes the program folder %LOCALAPPDATA%\Programs\Waysplit. It also deletes the data in %LOCALAPPDATA%\Waysplit: logs and core configurations. It deletes the device identifier only if you answer "да", which means yes, to its question. By default the identifier is kept, so that after a reinstall the provider does not count the computer as a new device.
  3. Delete any backups you saved yourself.
