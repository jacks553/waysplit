Политика конфиденциальности Waysplit

Обновлено 14 ноября 2026 г. Относится к расширению Chrome «Waysplit» и программе-компаньону для Windows (waysplit-host).

Waysplit — VPN только для браузера Chrome через серверы, которые добавляете вы сами. Разработчик Waysplit не получает никаких ваших данных: у Waysplit нет своего сервера, учётных записей, аналитики, рекламы и телеметрии. Всё, что вы вводите, остаётся на вашем компьютере, а по сети уходит только туда, куда это нужно для работы, — список ниже.

Что хранится и где

Только на вашем компьютере:

  • В Chrome (хранилище расширения): серверы — ссылки vless:// и hysteria2:// со всеми параметрами, включая ключи и пароли; адреса подписок и то, что пришло с ними (трафик, срок, сообщение провайдера); правила для сайтов вместе с их «доменами сайта» (см. «Что расширение видит в браузере»); настройки. Журнал событий для диагностики хранится только до закрытия браузера.
  • В папке компаньона %LOCALAPPDATA%\Waysplit: файлы настроек ядер sing-box и Xray (в них данные серверов), журналы работы (ключи, пароли и адреса подписок в них скрыты), идентификатор устройства (см. ниже).

Резервную копию («Настройки» → «Резервная копия» → «Сохранить копию») вы делаете сами, и в ней есть ссылки серверов с ключами — храните её как пароль.

Какие сетевые запросы делает Waysplit

  1. Ваши VPN-серверы. Сайты, которые по вашим настройкам идут через VPN, Chrome открывает через выбранный вами сервер.
  2. Ваши подписки. Компаньон скачивает список серверов по адресу подписки: когда вы её добавляете, по кнопке «Обновить» и по расписанию из настроек. В запросе есть заголовок User-Agent из настроек (по умолчанию v2rayN/7.0: с ним панели подписок отдают список серверов, а не веб-страницу). Если напрямую подписка не скачалась, а VPN включён, запрос повторяется через текущий сервер.
  3. Проверка связи с сервером («пинг»): запрос к https://www.gstatic.com/generate_204 (адрес Google для проверки соединения) через проверяемый сервер — по кнопке «Пинг» и для текущего сервера, когда открыто окно расширения.
  4. «Мой IP сейчас» (в диагностике): только по вашей кнопке — запрос к https://api.ipify.org через текущий сервер, чтобы показать, какой IP-адрес видят сайты.

Запросы 3 и 4 не содержат никаких сведений о вас; адресаты видят только IP-адрес вашего VPN-сервера. Что делают со своими данными ваш VPN-провайдер и провайдер подписки, определяют их правила.

Идентификатор устройства

Некоторые провайдеры подписок выдают серверы, только если программа назовёт своё устройство: так они ограничивают число устройств на подписку. Для этого у Waysplit есть идентификатор устройства:

  • это случайный номер, не связанный с оборудованием компьютера: не серийный номер, не MAC-адрес и не номер установки Windows;
  • он хранится только на этом компьютере — в файле %LOCALAPPDATA%\Waysplit\device-id;
  • он отправляется только провайдеру подписки и только если провайдер его требует: сначала подписка запрашивается без него, и только если без него провайдер серверов не даёт, запрос повторяется с ним. Такая подписка помечается в настройках как привязанная к устройству, и дальше она обновляется с идентификатором;
  • он отправляется только по защищённому соединению (https://).

Вместе с ним провайдер получает название системы (Windows), её версию (10 или 11) и модель устройства «Chrome» — так это устройство понятно называется в списке устройств у провайдера. Удалить идентификатор: «Удалить.cmd» спросит об этом (см. ниже), или удалите сам файл. Учтите: без него при повторной установке провайдер посчитает компьютер новым устройством. Отвязать устройство от подписки — в личном кабинете провайдера.

Что расширение видит в браузере

  • Адрес открытой вкладки — только её домен и только когда вы открываете окно Waysplit (разрешение activeTab): чтобы показать, идёт ли этот сайт через VPN, и дать добавить для него правило.
  • К каким доменам обращаются вкладки — только после вашего разрешения (необязательные разрешения webRequest и доступ к сайтам). Waysplit спрашивает его один раз, карточкой с объяснением в своём окне, или когда вы первый раз нажимаете «Домены этой вкладки»; без разрешения всё остальное работает. Расширение только смотрит имена доменов в запросах вкладок — не адреса страниц и не содержимое — и ничего в запросах не меняет и не блокирует. Эти имена нужны для двух вещей:
    • «Домены сайта». Видео, картинки и скрипты сайта часто лежат на других доменах. Если для сайта есть ваше правило «через VPN» и он открыт во вкладке, Waysplit добавляет к этому правилу домены, к которым обращается эта вкладка, — иначе через VPN шла бы только сама страница. Эти домены сохраняются в хранилище расширения как часть правила и остаются, пока вы не уберёте их (в меню «⋯» правила — «Домены сайта») или не удалите правило; они попадают в файл правил и в резервную копию, которые вы сохраняете сами. Запоминаются только домены вкладок с сайтами из ваших правил «через VPN»; общие сервисы (поиск, счётчики, реклама, библиотеки скриптов) и российские сайты не добавляются. Из вкладок в режиме инкогнито (если вы разрешили расширению в нём работать) домены к правилам не добавляются — от таких вкладок в хранилище расширения ничего не остаётся. Автоматическое добавление выключается в «Настройках» («Автоматически добавлять домены сайта»).
    • «Домены этой вкладки». По кнопке расширение показывает, к каким доменам обращалась вкладка, чтобы вы сами добавили нужные в правила. У каждой вкладки свой список (не больше 300 доменов), он начинается заново на новой странице и хранится только в памяти браузера до его закрытия.
    Всё это остаётся на вашем компьютере и никуда не отправляется. Разрешение можно отозвать в настройках Chrome (сведения о расширении → доступ к сайтам).
  • Значки сайтов (разрешение favicon) — у правил и у открытого сайта в окне Waysplit. Значки берутся только из памяти самого Chrome — тех сайтов, что вы уже открывали: Waysplit не делает за ними запросов в интернет и не обращается к сторонним сервисам, поэтому список ваших правил никуда не уходит. Нет значка — показывается первая буква домена.
  • Настройки прокси и WebRTC Chrome (proxy, privacy) — чтобы направлять сайты через VPN и чтобы WebRTC не выдавал ваш настоящий IP-адрес.

Адреса страниц и история браузера, содержимое страниц, вводимые данные и всё остальное не собираются и никуда не передаются.

Передача данных

Разработчик данные не получает, поэтому ничего не продаёт и никому не передаёт. Данные не используются для рекламы, не передаются брокерам данных, их не читают люди. Использование данных в Waysplit соответствует правилам Chrome Web Store User Data Policy, включая требования Limited Use.

Как всё удалить

  1. Удалите расширение в Chrome (правой кнопкой по значку Waysplit → «Удалить из Chrome») — вместе с ним удалятся серверы, подписки, правила и настройки.
  2. Запустите «Удалить.cmd» из архива компаньона или из папки %LOCALAPPDATA%\Programs\Waysplit — он снимет регистрацию компаньона в Chrome и удалит папку программы %LOCALAPPDATA%\Programs\Waysplit и данные в %LOCALAPPDATA%\Waysplit (журналы, настройки ядер). Идентификатор устройства он удалит, только если на его вопрос ответить «да»; по умолчанию идентификатор остаётся, чтобы при повторной установке провайдер не посчитал компьютер новым устройством.
  3. Резервные копии, которые вы сохраняли сами, удалите вручную.

Waysplit privacy policy

Last updated: November 14, 2026. Applies to the “Waysplit” Chrome extension and its Windows companion program (waysplit-host).

Waysplit is a browser-only VPN for Chrome that uses servers you add yourself. The Waysplit developer does not receive any of your data: Waysplit has no server of its own, no accounts, no analytics, no ads and no telemetry. Everything you enter stays on your computer; the only network requests are the ones needed for it to work, listed below.

What is stored and where

Only on your computer:

  • In Chrome (extension storage): servers — vless:// and hysteria2:// links with all their parameters, including keys and passwords; subscription URLs and what came with them (traffic, expiry date, provider message); site rules together with their “site domains” (see “What the extension sees in the browser”); settings. The diagnostic event log is kept only until the browser is closed.
  • In the companion folder %LOCALAPPDATA%\Waysplit: configuration files for the sing-box and Xray cores (they contain server details), operation logs (keys, passwords and subscription URLs are masked), and the device identifier (see below).

A backup (settings → “Резервная копия” → “Сохранить копию”, i.e. Backup → Save copy) is made only by you and contains server links with keys — keep it like a password.

Network requests Waysplit makes

  1. Your VPN servers. Sites that your settings send through the VPN are opened by Chrome via the server you selected.
  2. Your subscriptions. The companion downloads the server list from the subscription URL: when you add it, when you press “Обновить” (Update), and on the schedule set in the settings. The request carries the User-Agent header from the settings (by default v2rayN/7.0, which makes subscription panels return a server list instead of a web page). If the direct download fails while the VPN is on, the request is repeated through the current server.
  3. Server connectivity check (“ping”): a request to https://www.gstatic.com/generate_204 (Google’s connectivity-check address) through the server being checked — when you press “Пинг” (Ping), and for the current server while the extension window is open.
  4. “Мой IP сейчас” (My IP now), in diagnostics: only when you press the button — a request to https://api.ipify.org through the current server, to show which IP address websites see.

Requests 3 and 4 carry no information about you; their recipients see only the IP address of your VPN server. What your VPN provider and subscription provider do with their data is governed by their own policies.

Device identifier

Some subscription providers hand out servers only if the app identifies its device; this is how they limit the number of devices per subscription. For this, Waysplit has a device identifier:

  • it is a random number not tied to the computer’s hardware — not a serial number, not a MAC address and not the Windows installation ID;
  • it is stored only on this computer, in the file %LOCALAPPDATA%\Waysplit\device-id;
  • it is sent only to the subscription provider and only if the provider requires it: the subscription is first requested without it, and only if the provider returns no servers without it is the request repeated with it. Such a subscription is marked in the settings as bound to the device and is then updated with the identifier;
  • it is sent only over a secure connection (https://).

Together with it the provider receives the operating system name (Windows), its version (10 or 11) and the device model “Chrome”, so the device is recognizable in the provider’s device list. To delete the identifier, “Удалить.cmd” (Uninstall) will ask you about it (see below), or delete the file itself. Note that without it the provider will count the computer as a new device after a reinstall. To unbind the device from a subscription, use the provider’s account page.

What the extension sees in the browser

  • The address of the open tab — only its domain and only when you open the Waysplit window (activeTab permission): to show whether this site goes through the VPN and let you add a rule for it.
  • Which domains the tabs contact — only after you grant permission (optional webRequest and site access permissions). Waysplit asks for it once, with an explanation card in its own window, or the first time you press “Домены этой вкладки” (Domains of this tab); everything else works without it. The extension only looks at the domain names in the tabs’ requests — not page addresses and not content — and never modifies or blocks requests. These names are used for two things:
    • “Домены сайта” (Site domains). A site’s video, images and scripts are often served from other domains. If you have a “through VPN” rule for a site and the site is open in a tab, Waysplit adds the domains that this tab contacts to that rule — otherwise only the page itself would go through the VPN. These domains are saved in the extension storage as part of the rule and stay there until you remove them (rule menu “⋯” → “Домены сайта”) or delete the rule; they are included in the rules file and the backup that you save yourself. Only domains from tabs showing sites that have your “through VPN” rules are remembered; common services (search, analytics, ads, script libraries) and Russian sites are not added. Domains from incognito tabs (if you have allowed the extension to run in incognito) are never added to rules — nothing from such tabs is left in the extension storage. Automatic adding can be turned off in the settings (“Автоматически добавлять домены сайта”, Add site domains automatically).
    • “Домены этой вкладки” (Domains of this tab). On request the extension shows which domains a tab has contacted, so that you can add the ones you need to rules yourself. Each tab has its own list (at most 300 domains), which starts over on a new page and is kept only in browser memory until the browser is closed.
    All of this stays on your computer and is not sent anywhere. You can revoke the permission in Chrome’s settings (extension details → site access).
  • Website icons (favicon permission) — next to your site rules and the open site in the Waysplit window. Icons are read only from Chrome’s own local cache of sites you have already visited: Waysplit makes no network requests for them and uses no third-party services, so your list of rules never leaves the computer. If there is no icon, the first letter of the domain is shown.
  • Chrome proxy and WebRTC settings (proxy, privacy) — to route sites through the VPN and keep WebRTC from exposing your real IP address.

Page addresses and browsing history, page content, form input and anything else are not collected and are not transmitted anywhere.

Sharing

The developer receives no data, so nothing is sold or shared with anyone. Data is not used for advertising, is not transferred to data brokers, and is not read by humans. Waysplit’s use of data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

How to delete everything

  1. Remove the extension in Chrome (right-click the Waysplit icon → “Remove from Chrome”) — servers, subscriptions, rules and settings are deleted with it.
  2. Run “Удалить.cmd” (Uninstall) from the companion archive or from %LOCALAPPDATA%\Programs\Waysplit — it unregisters the companion from Chrome and deletes the program folder %LOCALAPPDATA%\Programs\Waysplit and the data in %LOCALAPPDATA%\Waysplit (logs, core configurations). It deletes the device identifier only if you answer “да” (yes) to its question; by default the identifier is kept, so that after a reinstall the provider does not count the computer as a new device.
  3. Delete any backups you saved yourself.
