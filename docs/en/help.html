Waysplit: install and FAQ

How to install Waysplit, update and remove it, and what to do if something goes wrong.

How to install

You need 64-bit Windows 10 or 11 and Google Chrome 120 or later. You also need your own servers: vless://… and hysteria2://… links or a subscription URL from your VPN provider. Administrator rights are not needed.

  1. Install the companion. Download Waysplit-companion.zip. Right-click the archive and choose "Extract All". In the extracted folder, run Install.cmd. Windows may show the "Windows protected your PC" window. This happens because the program has no paid digital signature and Windows does not know it. Click "More info", then "Run anyway". If a second window appears, click "Run" in it. The section Why Windows warns you explains more. Wait for the line "Done: the companion is installed". The installer does not need the internet. You can delete the extracted folder afterwards.
  2. Install the extension from the Chrome Web Store with the "Add to Chrome" button. Pin its icon to the toolbar: click the puzzle icon to the right of the address bar, then the pin next to Waysplit. The "Getting started" page opens automatically. Its first step should say "The companion is connected". If it says something else, click "Check again".
  3. Add a link or a subscription. On the "Getting started" page or in the Waysplit popup, paste server links or a subscription URL https://…. Click "Add", then "Turn on VPN". The popup screen shows "VPN is on" in large letters, and the toolbar icon turns green. To check, open https://api.ipify.org. It shows the IP of the server. Then turn the VPN off and reload the page. Now it shows your usual IP.

If the store does not open for you, install the extension by hand. The section Manual install explains how.

The sing-box and Xray cores are already in the companion archive, so the installer does not need the internet. The installer checks the files against the SHA256SUMS.txt list from the archive. This way it makes sure the archive is fully extracted and not damaged. If something is wrong, it tells you which file is missing or damaged. Then the installer copies the companion and the cores to %LOCALAPPDATA%\Programs\Waysplit and registers the companion in Chrome. A registered companion is available only to the Waysplit extension. You can also download the companion with the "Download" button on the "Getting started" page or in the extension popup.

The archive also holds Установить.cmd and Удалить.cmd. They do the same as Install.cmd and Uninstall.cmd. The installer shows its messages in Russian on Russian Windows and in English otherwise.

Why Windows warns you

Windows marks files from the internet as downloaded. It checks programs without a digital signature more strictly. The companion is not signed: a signature needs a paid certificate in the author's name. So when you run Install.cmd, Windows may show the "Windows protected your PC" window. It says "Publisher: Unknown publisher". Another possible window is "Open File - Security Warning". This does not mean the program has a virus. Windows simply does not know it yet. Check the SHA-256 of the archive and click "More info", then "Run anyway". In the second window, click "Run".

You can remove the warning in advance. Download the archive and check its SHA-256. Then, before extracting, right-click the archive and open "Properties". At the bottom of the "General" tab, check "Unblock" and click "OK". Do this only if the SHA-256 matches.

How to check the archive

Every file has a fingerprint, its SHA-256. If a single byte of the archive changes, the fingerprint changes too. The fingerprints of the real archives are on the release page. They are written in the release notes and attached as the files Waysplit-companion.zip.sha256 and Waysplit-extension.zip.sha256.

  1. Click "Start", type PowerShell and open Windows PowerShell.
  2. Run the command below. It is written for an archive in the Downloads folder. If the archive is somewhere else, use its path. 
    Get-FileHash "$env:USERPROFILE\Downloads\Waysplit-companion.zip"
  3. Compare the Hash line with the fingerprint on the release page. Check all 64 characters. Upper and lower case do not matter. If they differ, do not run the program and download the archive again from the release page.

The extension archive for a manual install is checked the same way. Put Waysplit-extension.zip into the command.

Manual install (fallback)

If the Chrome Web Store is not available to you, you can install Waysplit by hand from the GitHub release. It is the same version as in the store. The companion is the same too. Install it first, as in step 1 of How to install.

  1. Download the extension archive Waysplit-extension.zip from the release page.
  2. Extract it to a permanent folder. Right-click Waysplit-extension.zip and choose "Extract All". Pick a folder you will not delete or move, for example Documents\Waysplit-extension. Chrome runs the extension right from this folder. If you delete it, the extension disappears.
  3. Load the extension into Chrome. Paste chrome://extensions into the address bar and open that page. Turn on "Developer mode" at the top right. Click "Load unpacked" and choose the folder from step 2. You need the folder that holds the manifest.json file. Then pin the icon: click the puzzle icon to the right of the address bar, then the pin next to Waysplit.
  4. Add a link or a subscription, as in step 3 of "How to install".

Chrome may remind you about developer mode at startup. It warns this way about any extension installed by hand. Do not disable the extension, just close the reminder.

A manual copy does not update automatically. To update it, download the new Waysplit-extension.zip and extract it to the same folder, replacing the files. Then open chrome://extensions and click the round arrow on the Waysplit card.

Do not install a manual copy next to the store version in the same Chrome profile. Two copies fight over the proxy, and the VPN works through one or the other at random. When the store becomes available, switch to it. The next section explains how.

Switching from the manual version to the store version

If you installed Waysplit by hand from Waysplit-extension.zip, switch to the store version. Chrome updates it automatically and does not remind you about developer mode. Each copy has its own servers, subscriptions and rules, so follow this order.

  1. Save a backup in the manual version. Open the "Settings" tab and click "Save backup" in the "Backup" section. The file holds secrets: server links and subscription URLs. Keep it like a password. Then turn the VPN off.
  2. Install Waysplit from the Chrome Web Store.
  3. Remove the manual version. Open chrome://extensions and click "Remove" on its card. You can tell it by the "Unpacked extension" label. After that you can delete the Waysplit-extension folder too. If you have no other extensions installed by hand, you can also turn off "Developer mode".
  4. Restore your data in the store version. Open the "Settings" tab, click "Restore from backup" in the "Backup" section and choose the file from step 1. Servers, subscriptions, rules, favorites and settings come back. It is better to delete the backup file afterwards.

You do not need to reinstall the companion, it works with both versions. The link between a subscription and the device stays too, because the companion keeps the device ID.

Updating

Chrome updates the store extension automatically. The section Manual install explains how to update a manual copy. Better still, switch to the store version.

To update the companion, download the new archive and run Install.cmd again. If the extension needs a newer companion, it says "The companion is outdated" and gives a download link. Servers, rules and settings are stored in Chrome and survive an update.

Uninstalling

  1. Remove the extension. Right-click the Waysplit icon and choose "Remove from Chrome". Servers, subscriptions and rules are removed with it. If you may need them later, save a backup first. To do that, open the "Settings" tab and click "Save backup" in the "Backup" section.
  2. Remove the companion. Run Uninstall.cmd from the archive or from the folder %LOCALAPPDATA%\Programs\Waysplit. It unregisters the companion from Chrome and deletes the program and its data. The data is in %LOCALAPPDATA%\Waysplit: logs and core settings. If something has to be deleted by hand, it says so at the end.
  3. Uninstall.cmd asks about the device ID separately. If you just press Enter, the ID stays. Then your subscription provider will see the same computer after a new install. If you answer "yes", the ID is deleted. Then the provider will treat the computer as a new device after a reinstall, and the device limit of your subscription may run out. If you no longer need Waysplit on this computer, delete the ID and unlink the device in your provider account.

FAQ

Where do I get servers?

From your VPN provider. It gives you vless:// and hysteria2:// links or a subscription URL. You can also set up your own server. Waysplit works only as a client.

Why a separate program?

A Chrome extension cannot speak VLESS and Hysteria2 on its own. The sing-box and Xray cores do that, and the companion starts them.

What does Waysplit know about me?

Waysplit sends nothing to the developer. It talks over the network only to your servers and to your subscription. It also makes two checks: the ping and "My current IP". The privacy policy lists everything.

What does "linked to this computer as a device" mean?

Some providers give servers only to devices. Then Waysplit repeats the request with a device ID. It is a random number, not tied to your hardware. It is stored only on this computer. It goes only to the subscription provider, only when the provider requires it, and only over https://. In its device list the provider will see a device named "Chrome". If the device limit is reached, Waysplit says so.

Does it work on macOS or Linux?

Not yet. The companion exists only for 64-bit Windows 10 and 11.

Chrome says the extension is not trusted by Enhanced Safe Browsing

Chrome marks extensions from new developers this way. The mark goes away on its own in a few months. You can continue the installation.

Companion messages are in Russian while the popup is in English

Companion 1.2.0 and later sends its messages in the language of the popup. An older companion writes only in Russian. Update the companion: download the new archive and run Install.cmd.

An antivirus deleted or blocked the companion or a core

Antivirus programs sometimes flag new programs by mistake. This happens to VPN cores too. First check the SHA-256 of the archive against the release page, as in the section "How to check the archive". If the fingerprint matches, restore the file from quarantine and add an exclusion for the folder %LOCALAPPDATA%\Programs\Waysplit.

To add an exclusion, open "Start" and run "Windows Security". Open "Virus & threat protection" and click "Manage settings". In the "Exclusions" section click "Add or remove exclusions", then "Add an exclusion", and choose "Folder".

Then run Install.cmd again from the extracted archive. If the antivirus deleted the file there too, extract the archive again. Add an exclusion only if the antivirus really gets in the way.

Windows 11 does not let the companion run at all

This happens when Smart App Control is on in Windows. It blocks unsigned programs, and it cannot make an exception for a single program.

What do the icon colors mean?

  • gray: the VPN is off;
  • green: the VPN is on;
  • yellow: the VPN is off, but "through VPN" site rules are working;
  • red: an error. The Waysplit popup shows what happened.

If something goes wrong

In the new design the screen shows a short name of the problem in large letters, for example "No companion" or "Port in use". The line below gives the reason. The table lists the reasons.

What you seeWhat to do
"Companion is not installed"Install the companion, as in step 1 of "How to install". Then click the button again. If that does not help, restart Chrome.
"The companion does not accept this extension"Download the companion again and run Install.cmd.
"The companion is outdated"Download the new companion version and run Install.cmd.
"sing-box was not found…", or "Xray was not found…" for XHTTP serversRun Install.cmd again from the extracted archive: the cores are in the archive. If the installer says "the file is missing" or "the file is damaged", download the archive again and extract all of it. If the file disappears again, an antivirus deletes it. See the FAQ above.
The installer says "the archive was not fully extracted or is damaged"Download the archive again and check its SHA-256. Extract the whole archive with "Extract All". Do not run Install.cmd right from inside the archive.
"Port 27105 is in use by another program"Close the program that took the port. It may be another VPN client, for example. Or change the field "Local server ports, starting from" on the "Settings" tab, for example to 28101.
"No response" or "Server is not responding"Choose another server or click "Fastest" on the "Servers" tab. With Hysteria2 a common cause is that the network blocks UDP.
"Another extension is controlling the proxy"On the chrome://extensions page, turn off the other VPN or proxy extension. Only one extension can control the Chrome proxy.
The VPN is off, but sites see the VPN IPThe site may have a "through VPN" rule, then the icon is yellow. Or Windows has the system proxy of another VPN client turned on. Turn it off.
A message that the subscription URL is unencryptedThe provider requires a device ID, and it is not sent over http://. Ask your provider for an https:// URL.
Nothing helpsOpen the "Settings" tab, then "Diagnostics", and click "Copy debug report". Attach the report to your question in Issues. The report has no server links, UUIDs, passwords or subscription URLs.
