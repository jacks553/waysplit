Waysplit — компаньон {{VERSION}}
================================

Waysplit — расширение Chrome: VPN только для браузера через ваши серверы
(VLESS, в том числе XHTTP, и Hysteria2). Часть сайтов — через VPN, часть — напрямую.
Само расширение к серверам не подключается: это делает компаньон — небольшая
программа для Windows 10 и 11 из этого архива. Её запускает Chrome, сами вы её
не открываете.

Серверов Waysplit не даёт: нужны свои ссылки (vless://, hysteria2://) или
подписка от вашего провайдера.


Установка
---------
1. Распакуйте архив: правой кнопкой по нему → «Извлечь всё…».
2. В распакованной папке запустите «Установить.cmd».
   Windows может предупредить — см. «Почему Windows предупреждает» ниже.
3. Дождитесь «Готово» и вернитесь в Chrome.

Права администратора и интернет не нужны: ядра sing-box и Xray уже лежат в
архиве. Установщик:
  • сверяет файлы с SHA256SUMS.txt: архив распакован целиком и не повреждён
    (если нет — скажет, какого файла не хватает или какой испорчен);
  • копирует компаньон и ядра в %LOCALAPPDATA%\Programs\Waysplit;
  • регистрирует компаньон в Chrome (только для расширения Waysplit).

Обновление — то же самое: скачайте новый архив и запустите «Установить.cmd».
Серверы, правила и настройки хранятся в Chrome и не пропадают.


Почему Windows предупреждает
----------------------------
Файлы из интернета Windows помечает как «скачанные», а программы без цифровой
подписи проверяет строже. Компаньон не подписан: подпись — это платный
сертификат на имя автора. Поэтому при запуске «Установить.cmd» Windows может
показать «Система Windows защитила ваш компьютер» с «Издатель: неизвестный
издатель» или «Предупреждение системы безопасности». Это не значит, что в
программе вирус, — только что Windows её ещё не знает. Сначала сверьте SHA-256
архива (см. «Проверка архива»), потом нажмите «Подробнее» → «Выполнить в любом
случае» (или «Запустить» во втором окне).

В следующий раз (например, при обновлении) можно обойтись без предупреждения:
скачав архив и сверив SHA-256, ещё до распаковки откройте его «Свойства»
(правой кнопкой по архиву) и внизу на вкладке «Общие» отметьте «Разблокировать»
→ «ОК». Делайте так, только если SHA-256 совпала.


Проверка архива
---------------
SHA-256 — «отпечаток» файла: если в архиве изменился хоть один байт, отпечаток
будет другим. Отпечаток настоящего архива опубликован на странице выпуска
(в описании и файлом Waysplit-companion.zip.sha256):
{{REPO_URL}}/releases
1. Нажмите «Пуск», наберите PowerShell и откройте «Windows PowerShell».
2. Выполните (если архив скачан в папку «Загрузки»):
     Get-FileHash "$env:USERPROFILE\Downloads\Waysplit-companion.zip"
   Архив в другой папке — укажите путь к нему.
3. Сравните строку Hash с отпечатком на странице выпуска — все 64 знака
   (большие и маленькие буквы не важны). Не совпадает — не запускайте:
   скачайте архив заново со страницы выпуска.


Удаление
--------
Запустите «Удалить.cmd» (он есть и здесь, и в папке
%LOCALAPPDATA%\Programs\Waysplit). Он снимет регистрацию в Chrome и удалит
программу и её данные (%LOCALAPPDATA%\Waysplit: журналы, настройки ядер).

Идентификатор устройства он спросит отдельно. По нему провайдер подписки
узнаёт этот компьютер, если подписка привязана к устройству. Просто Enter —
оставить (поставите Waysplit снова — провайдер увидит тот же компьютер).
«да» — удалить: тогда при повторной установке провайдер посчитает компьютер
новым устройством, а лимит устройств у подписки может закончиться.

Само расширение удалите в Chrome: правой кнопкой по значку Waysplit →
«Удалить из Chrome».


Если что-то не так
------------------
• Установщик пишет «нет файла» или «файл повреждён» — архив распакован не
  целиком, скачался с ошибкой или файл удалил антивирус. Скачайте архив
  заново, сверьте SHA-256 и распакуйте целиком.
• Антивирус удалил или заблокировал waysplit-host.exe, sing-box.exe или
  xray.exe — антивирусы иногда по ошибке считают опасными новые программы,
  в том числе ядра VPN. Если SHA-256 архива совпала, верните файл из
  карантина, добавьте исключение для папки %LOCALAPPDATA%\Programs\Waysplit и
  запустите «Установить.cmd» ещё раз.
• Включено «Интеллектуальное управление приложениями» (Smart App Control,
  Windows 11) — оно может не пустить неподписанные программы, и обойти это нельзя.
• Подробности ошибок — в окне расширения: «Настройки» → «Диагностика».
