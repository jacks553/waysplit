# Изменения

## 1.2.1: кнопка языка в шапке

Расширение обновится из Chrome Web Store само, когда Google проверит версию 1.2.1. Компаньон 1.2.1 отличается от 1.2.0 только номером версии. Обновлять его не нужно.

- В шапке окна, слева от "?", появилась кнопка языка: RU или EN. По нажатию открывается меню: Русский, English, как в Chrome. Язык меняется сразу.
- Такая же кнопка есть на странице "Начало работы", справа вверху.
- Выбор "Язык" в настройках остался. Кнопка меняет ту же настройку.

### In English

Version 1.2.1 adds a language button to the popup header, to the left of "?". It shows RU or EN and opens a menu: Русский, English, same as Chrome. The same button is on the Getting started page. The companion is unchanged except for its version number.

## 1.2.0: английский язык

Расширение обновится из Chrome Web Store само, когда Google проверит версию 1.2.0. До этого в магазине будет 1.1.0, она работает и с новым компаньоном.

Расширение Chrome 1.2.0 и компаньон для Windows 1.2.0. Расширение 1.2.0 работает и с компаньонами 1.0.0 и 1.1.0. Новый компаньон нужен, чтобы его сообщения были на языке окна.

### Язык окна

- Окно расширения, страница "Начало работы" и подсказка значка теперь есть на русском и английском.
- В настройках появился выбор "Язык": как в Chrome, Русский или English. Язык меняется сразу, перезапускать Chrome не нужно.
- У тех, кто обновился с прежней версии, язык остаётся русским. При новой установке язык берётся из Chrome: русский в русском Chrome, английский в остальных.
- Описание расширения в магазине и на странице `chrome://extensions` тоже на двух языках.
- Резервная копия хранит выбранный язык. Копии версий 1.0.0 и 1.1.0 читаются как раньше.

### Компаньон

- Сообщения компаньона показываются на языке окна: причины, по которым ссылка не стала сервером, ошибки подписки, запуска ядер и пинга. Для этого нужен компаньон 1.2.0.
- Со старым компаньоном эти сообщения остаются русскими. В английском окне в настройках появляется строка с просьбой обновить компаньон.
- В архиве компаньона появились `Install.cmd`, `Uninstall.cmd` и `README.txt` с инструкцией на английском. Файлы с русскими именами остались.
- Установщик пишет по-русски в русской Windows и по-английски в остальных.
- Инструкция "Прочитай меня" переписана проще.

### Сайт и README

- Ссылки "Помощь" и "Частые вопросы" в окне ведут на страницы сайта проекта на языке окна.
- README стал коротким, подробности переехали на страницы сайта. Появился README на английском.

### Что осталось на русском

Отчёт "Проверить подписку" пока только на русском. Журналы компаньона и ядер тоже.

Version 1.2.0 adds English. The popup, the Getting started page, the installer and the companion messages are now available in English and Russian. Choose the language in Settings. Update the companion to 1.2.0 to see its messages in English. The "Check subscription" report is still in Russian only.

## 1.1.0: домены сайта, российские сайты без VPN

Расширение обновится из Chrome Web Store само, когда Google проверит версию 1.1.0. До этого в магазине будет 1.0.0, она работает и с новым компаньоном.

Расширение Chrome 1.1.0 и компаньон для Windows 1.1.0. Расширение 1.1.0 работает и с компаньоном 1.0.0. Новый компаньон нужен только ради понятного сообщения о ссылках Happ.

### Домены сайта

Раньше правило на youtube.com пускало через VPN только саму страницу. Видео и картинки с googlevideo.com и ytimg.com шли без VPN. Теперь к правилу привязываются домены сайта. Они идут так же, как само правило, и удаляются вместе с ним. В строке правила видно "+N доменов сайта". В меню "⋯" правила есть пункт "Домены сайта…" со списком, из которого можно убрать любой домен.

- Домены берутся из готовых наборов. Правило на главный домен набора сразу получает домены набора. Главные домены наборов: youtube.com, instagram.com, telegram.org, discord.com и chatgpt.com. Правилам, которые были до обновления, домены наборов привязываются один раз при обновлении.
- Домены добавляются сами, пока сайт открыт. Так работают только правила "через VPN". Домены, к которым обращается вкладка с сайтом, добавляются к его правилу, а на Главной появляется подсказка обновить вкладку. Для этого нужно разрешение Chrome видеть запросы вкладок. Waysplit спрашивает его один раз и объясняет зачем. Без разрешения работают только наборы. Выключается это в настройках галочкой "Автоматически добавлять домены сайта".
- Подсказка "обновите вкладку" появляется у каждой открытой вкладки этого сайта. Она не теряется и не висит зря. Если правило удалили или вкладку закрыли, подсказки нет.
- Из вкладок инкогнито домены не собираются, даже если вы разрешили расширению там работать. Правила хранятся на диске, а от инкогнито там ничего оставаться не должно. "Домены этой вкладки" в инкогнито работают, потому что этот список живёт только в памяти браузера.
- Привязанный домен действует во всех вкладках, потому что Chrome выбирает прокси по адресу запроса. Поэтому сами не добавляются общие сервисы: Google, счётчики, реклама и библиотеки скриптов. Не добавляются и российские зоны и сайты, а ещё домены со своим правилом. У общих хостингов вроде cloudfront.net и github.io добавляется только полное имя.
- Файл правил и резервная копия теперь хранят домены сайта. Файлы версии 1.0.0 читаются.

### Российские сайты без VPN

Это новый переключатель на Главной. Такая же галочка есть в настройках и на странице "Начало работы". По умолчанию он выключен. Когда он включён, зоны .ru, .рф, .su и российские сервисы на других доменах идут без VPN, даже когда VPN включён. Это VK, Одноклассники, Яндекс, Wildberries, Avito и другие.

Это настройка, а не правила. Ваши правила и домены сайта важнее, и правило "через VPN" для отдельного российского сайта работает. Уже добавленные правила не трогаются. Блок "Этот сайт" пишет "Без VPN: российский сайт", а на вкладке "Правила" появляется напоминание. Набор "Российские сайты без VPN" раньше назывался "Российские сайты напрямую". Теперь в нём есть и российские сервисы на нероссийских доменах.

### Окно

Окно расширения стало выше: 400×600. На невысоких экранах, где столько не помещается, высота остаётся 580, как раньше. Главная стала чуть плотнее. Под новой строкой о российских сайтах блок "Этот сайт" виден целиком, вместе со ссылками "Убрать правило" и "Домены этой вкладки". Для этого два пояснения стали короче и помещаются в одну строку. Первое говорит, что у сайта нет правила и он идёт как остальные. Второе стоит под статусом "работают правила" и говорит, сколько сайтов из правил идёт через VPN.

### Читаемость и доступность

Окно проверено в обеих темах. Вот что исправлено:

- Контраст мелкого текста теперь не ниже 4,5:1. В светлой теме исправлены жёлтые строки и главный статус, в тёмной залитые кнопки, подсказки в полях и красное сообщение об ошибке.
- Выключенный переключатель и границы полей стали заметнее. Отключённое правило теперь читается.
- Короткие сообщения об успехе внизу окна исчезают сами. Ошибки и сообщения с причиной или указанием остаются, пока их не закроют крестиком.
- У сервера без ответа есть подпись "нет ответа".
- После удаления правила есть кнопка "Вернуть". Правило возвращается вместе с доменами сайта.
- В меню "⋯" виден фокус с клавиатуры. Текстовые ссылки стали крупнее, а корзина и "⋯" стоят дальше друг от друга.
- Везде одно слово "без VPN" вместо двух, раньше было ещё "Напрямую". Настройка "Открыть напрямую" теперь называется "Открыть без VPN", а набор называется "Российские сайты без VPN".
- В настройках у каждой галочки название и пояснение теперь отдельно. Кнопка в жёлтой строке называется "Включить правила". На экране подписки осталась одна залитая кнопка.

### Другие изменения

- В набор YouTube добавлен yt3.googleusercontent.com, с него грузятся аватарки каналов.
- Адрес с точкой в конце, например `ya.ru.`, теперь считается тем же сайтом. Окно показывает его правило, а раньше писало "Правила нет", хотя сайт шёл по правилу. Для такой вкладки работают "Домены этой вкладки" и автоматическое добавление доменов сайта.
- Открытое окно расширения больше не перерисовывается от запросов вкладок. При просмотре видео это случалось несколько раз в минуту.
- Компаньон больше не пишет "ссылка не распознана" на вставленную ссылку `happ://crypt…`. Теперь он объясняет, что ссылка зашифрована для приложения Happ и открыть её может только Happ. И советует попросить у провайдера обычную ссылку на подписку `https://…`. Ссылка `happ://add/https://…` теперь добавляется как подписка.
- В политике конфиденциальности теперь написано, что домены сайта хранятся на компьютере как часть правила. Раньше имена доменов вкладок хранились только до закрытия браузера.

## 1.0.0: первый выпуск

Расширение Chrome 1.0.0 и компаньон для Windows 1.0.0.

- VPN только для Chrome через ваши серверы VLESS и Hysteria2. VLESS работает с Reality, Vision, XHTTP и VLESS Encryption. Серверы XHTTP и VLESS Encryption запускает ядро Xray, остальные запускает sing-box.
- Всё управление находится в окне расширения, на вкладках Главная, Серверы, Правила и Настройки. Кнопка "Развернуть" открывает то же самое на всю вкладку. Для открытого сайта прямо на Главной есть переключатель "через VPN / напрямую" и выбор сервера. В выборе сервера есть поиск, избранное со звёздочкой, группы по подпискам и полоски задержки. Значки сайтов берутся только из памяти Chrome.
- Правила для сайтов бывают двух видов: "всегда через VPN" и "всегда без VPN". Через VPN сайт идёт через текущий или выбранный сервер. Правила можно задавать и для доменных зон, есть готовые наборы. Правила могут работать и при выключенном VPN.
- Подписки: обычный список ссылок, Xray JSON, sing-box JSON и Clash или Mihomo YAML. Есть автообновление, трафик и срок, сообщения провайдера. Работают и подписки с привязкой к устройству. Идентификатор отправляется только провайдеру, только если тот его требует, и только по https.
- Пинг серверов и выбор самого быстрого, флаги стран, защита WebRTC, резервная копия и диагностика без секретов. Если сервер недоступен, можно выбрать "Не открывать сайт" или "Открыть напрямую".
- Установщик компаньона для пользователей: `Установить.cmd` и `Удалить.cmd`. Права администратора и интернет ему не нужны, потому что ядра sing-box 1.14.4 и Xray 26.10.31 лежат в архиве. Это официальные выпуски, их SHA-256 сверены при сборке. Лицензии и ссылки на исходный код записаны в `CORES.txt`, а архивы исходного кода лежат на странице выпуска. Перед установкой установщик сверяет файлы с `SHA256SUMS.txt` и не ставит неполный или испорченный архив. `Удалить.cmd` спрашивает, удалять ли идентификатор устройства. По умолчанию идентификатор остаётся, и после повторной установки провайдер видит тот же компьютер.
- У `waysplit-host.exe` есть значок и сведения о версии. Их видно в свойствах файла и в диспетчере задач, там программа называется "Компаньон Waysplit".
- Компаньон работает и с версией из Chrome Web Store, и с расширением, поставленным вручную.
- Расширение лежит в [Chrome Web Store](https://chromewebstore.google.com/detail/waysplit/fdgapnefknckjikbklcanoklhnmcgklg). Если магазин недоступен, его можно поставить вручную из `Waysplit-extension.zip` в этом выпуске. Как это сделать, написано ниже.

В выпуске лежат `Waysplit-companion.zip` с компаньоном и `Waysplit-extension.zip` с расширением для ручной установки. Постоянные ссылки на последний выпуск: https://github.com/jacks553/waysplit/releases/latest/download/Waysplit-companion.zip и https://github.com/jacks553/waysplit/releases/latest/download/Waysplit-extension.zip. Их SHA-256 написаны ниже и лежат рядом файлами `.sha256`.
