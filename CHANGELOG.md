# Изменения

## 1.1.0 — домены сайта, российские сайты без VPN

Расширение обновится само из Chrome Web Store, когда Google проверит версию 1.1.0; до этого там 1.0.0 — она работает и с новым компаньоном.

Расширение Chrome 1.1.0 и компаньон для Windows 1.1.0. Расширение 1.1.0 работает и с компаньоном 1.0.0; новый компаньон нужен только ради понятного сообщения о ссылках Happ.

- **Домены сайта.** Правило на youtube.com раньше пускало через VPN только саму страницу, а видео и картинки (googlevideo.com, ytimg.com) шли без VPN. Теперь к правилу привязываются домены сайта: они идут так же, как правило, и удаляются вместе с ним. В строке правила — «+N доменов сайта», в меню «⋯» — «Домены сайта…» со списком, где любой домен можно убрать.
  - Из готовых наборов: правило на главный домен набора (youtube.com, instagram.com, telegram.org, discord.com, chatgpt.com) сразу получает домены набора. Уже существующим правилам они привязываются при обновлении, один раз.
  - Сами, пока сайт открыт (только для правил «через VPN»): домены, к которым обращается вкладка с сайтом, добавляются к его правилу; на «Главной» — подсказка «Найдены новые домены сайта — обновите вкладку». Нужно разрешение Chrome видеть запросы вкладок — Waysplit спрашивает его один раз, с объяснением; без него работают только наборы. Выключается в «Настройках» («Автоматически добавлять домены сайта»).
  - Подсказка «обновите вкладку» появляется у каждой открытой вкладки этого сайта, не теряется и не висит зря: правило удалили или вкладку закрыли — её нет.
  - Из вкладок инкогнито (если вы разрешили расширению работать в инкогнито) домены не собираются: правила хранятся на диске, а от инкогнито там ничего оставаться не должно. «Домены этой вкладки» в инкогнито работают — этот список живёт только в памяти браузера.
  - Привязанный домен действует во всех вкладках (Chrome выбирает прокси по адресу запроса), поэтому сами не добавляются общие сервисы (Google, счётчики, реклама, библиотеки скриптов), российские зоны и сайты, домены со своим правилом; у общих хостингов (cloudfront.net, github.io и т. п.) добавляется только полное имя.
  - Файл правил и резервная копия — с доменами сайта; файлы версии 1.0.0 читаются.
- **«Российские сайты — без VPN»** — переключатель на «Главной» (он же — в «Настройках» и на «Начале работы»), по умолчанию выключен. Включён — зоны .ru, .рф, .su и российские сервисы на других доменах (VK, Одноклассники, Яндекс, Wildberries, Avito и другие) идут без VPN, даже когда VPN включён. Это настройка, а не правила: ваши правила и домены сайта важнее (правило «через VPN» для отдельного российского сайта работает), уже добавленные правила не трогаются. Блок «Этот сайт» пишет «Без VPN: российский сайт», на вкладке «Правила» — напоминание. Набор «Российские сайты без VPN» (раньше — «Российские сайты напрямую») дополнен российскими сервисами на нероссийских доменах.
- Окно расширения стало выше — 400×600 (на невысоких экранах, где столько не помещается, — 580, как раньше), а «Главная» — чуть плотнее: под новой строкой «Российские сайты — без VPN» блок «Этот сайт» виден целиком, вместе со ссылками «Убрать правило» и «Домены этой вкладки». Для этого пояснения стали короче: «Правила нет — как у остальных сайтов: через VPN» и строка под статусом «работают правила» («Через VPN — 3 сайта из правил») — в одну строку.
- **Читаемость и доступность** (по проверке окна в обеих темах). Контраст мелкого текста — не ниже 4,5:1: жёлтые строки и главный статус в светлой теме, залитые кнопки, подсказки в полях и красное сообщение об ошибке в тёмной; заметнее выключенный переключатель и границы полей; отключённое правило читается. Сообщения внизу окна: короткие об успехе исчезают сами, ошибки и сообщения с причиной или указанием остаются до крестика. У сервера без ответа — подпись «нет ответа». После удаления правила — «Вернуть» (вместе с доменами сайта). В меню «⋯» виден фокус с клавиатуры; текстовые ссылки и расстояние между корзиной и «⋯» — крупнее. Одно слово вместо двух: везде «без VPN» (было ещё «Напрямую»; настройка «Открыть напрямую» теперь «Открыть без VPN», набор — «Российские сайты без VPN»). В «Настройках» у каждой галочки название и пояснение отдельно; кнопка в жёлтой строке — «Включить правила»; на экране подписки залитая кнопка одна.
- В набор YouTube добавлен yt3.googleusercontent.com (аватарки каналов).
- Адрес с точкой в конце (`ya.ru.`) — тот же сайт: окно показывает его правило (раньше писало «Правила нет», хотя сайт шёл по правилу), для такой вкладки работают «Домены этой вкладки» и автоматическое добавление доменов сайта.
- Открытое окно расширения больше не перерисовывается от запросов вкладок (при просмотре видео это случалось несколько раз в минуту).
- Компаньон: вставленная ссылка `happ://crypt…` больше не «ссылка не распознана», а понятное «Ссылка зашифрована для приложения Happ — открыть её может только Happ. Попросите у провайдера обычную ссылку на подписку (https://…)»; ссылка `happ://add/https://…` добавляется как подписка.
- Политика конфиденциальности: домены сайта хранятся на компьютере как часть правила (раньше имена доменов вкладок хранились только до закрытия браузера).

## 1.0.0 — первый выпуск

Расширение Chrome 1.0.0 и компаньон для Windows 1.0.0.

- VPN только для Chrome через ваши серверы: VLESS (в том числе Reality, Vision, XHTTP и VLESS Encryption) и Hysteria2. Серверы XHTTP и VLESS Encryption запускаются ядром Xray, остальные — sing-box.
- Всё управление — в окне расширения, на вкладках «Главная · Серверы · Правила · Настройки»; «Развернуть» открывает то же самое на всю вкладку. Для открытого сайта — переключатель «через VPN / напрямую» и выбор сервера прямо на главной. Выбор сервера: поиск, избранное (звёздочка), группы по подпискам, полоски задержки. Значки сайтов — только из памяти Chrome.
- Правила для сайтов: «всегда через VPN» (через текущий или выбранный сервер) и «всегда без VPN», доменные зоны, готовые наборы; правила могут работать и при выключенном VPN.
- Подписки: обычный список ссылок, Xray JSON, sing-box JSON, Clash / Mihomo YAML; автообновление, трафик и срок, сообщения провайдера; подписки с привязкой к устройству (идентификатор отправляется только провайдеру, только если он его требует, и только по https).
- Пинг серверов и выбор самого быстрого, флаги стран, защита WebRTC, «Не открывать сайт» или «Открыть напрямую» при недоступном сервере, резервная копия, диагностика без секретов.
- Установщик компаньона для пользователей: «Установить.cmd» / «Удалить.cmd», без прав администратора и без интернета: ядра sing-box 1.14.4 и Xray 26.10.31 лежат в архиве (официальные выпуски, SHA-256 сверены при сборке; лицензии и ссылки на исходный код — `CORES.txt`, архивы исходного кода — на странице выпуска). Перед установкой он сверяет файлы с `SHA256SUMS.txt` и не ставит неполный или испорченный архив. «Удалить.cmd» спрашивает, удалять ли идентификатор устройства (по умолчанию он остаётся, и после повторной установки провайдер видит тот же компьютер).
- У `waysplit-host.exe` — значок и сведения о версии (видны в «Свойствах» файла и в диспетчере задач: «Компаньон Waysplit»).
- Компаньон работает и с версией из Chrome Web Store, и с расширением, поставленным вручную.
- Расширение — в [Chrome Web Store](https://chromewebstore.google.com/detail/waysplit/fdgapnefknckjikbklcanoklhnmcgklg). Если магазин недоступен, его можно поставить вручную: `Waysplit-extension.zip` в этом выпуске (ниже — как).

В выпуске — `Waysplit-companion.zip` (компаньон) и `Waysplit-extension.zip` (расширение для ручной установки); постоянные ссылки на последний выпуск: https://github.com/jacks553/waysplit/releases/latest/download/Waysplit-companion.zip и https://github.com/jacks553/waysplit/releases/latest/download/Waysplit-extension.zip. Их SHA-256 — ниже и файлами `.sha256` рядом.
