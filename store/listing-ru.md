# Карточка Waysplit в Chrome Web Store

Тексты для вкладки «Описание в магазине» (Store listing). Сверено с документацией магазина 8 ноября 2026 г. (developer.chrome.com/docs/webstore: cws-dashboard-listing, best_listing, images, program-policies).

Имя на GitHub в ссылках — `jacks553`.

## Название

**Waysplit** — берётся из manifest.json (поле `name`); в панели его не поменять, только новой версией.

Проверка названия (8 ноября 2026 г.): поиск «Waysplit» в Chrome Web Store ничего не находит, поиск в интернете — тоже, продукта с таким именем нет. Похожие по написанию — WSplit (таймер для спидранов) и WavSplit / waveSplit (нарезка звуковых файлов): другие области, путаницы не будет.

## Краткое описание

Берётся из manifest.json (поле `description`, не длиннее 132 символов; в панели не меняется). Сейчас — 128 символов:

> VPN для Chrome через ваши серверы VLESS, XHTTP и Hysteria2: часть сайтов через VPN, часть напрямую. Нужен компаньон для Windows.

## Подробное описание

Вставить в поле «Описание» (Description) целиком:

```text
Waysplit — VPN только для браузера Chrome через ваши собственные серверы. Нужные сайты идут через VPN, остальные — напрямую. Другие программы на компьютере VPN не затрагивает.

Что умеет
• Серверы VLESS (в том числе Reality, Vision и XHTTP) и Hysteria2 — по ссылкам vless:// и hysteria2:// или по подписке вашего провайдера.
• Правила для сайтов: «всегда через VPN» (через текущий или выбранный сервер) и «всегда без VPN». Правило действует на все поддомены, можно задать целую доменную зону.
• Правила могут работать и при выключенном VPN: через VPN идут только выбранные сайты.
• Всё управление — прямо в окне расширения, на вкладках «Главная», «Серверы», «Правила», «Настройки». Для открытого сайта — переключатель «через VPN / напрямую» и выбор сервера прямо на главной.
• Выбор сервера в один щелчок, избранные серверы, проверка пинга, выбор сервера с наименьшей задержкой.
• Защита от утечек: пока VPN включён, WebRTC не выдаёт ваш настоящий IP-адрес; если сервер недоступен, сайт не откроется напрямую (или откроется — как вы настроите).
• Подписки обновляются сами; видны трафик, срок действия и сообщения провайдера.
• Диагностика и отчёт для отладки без ключей и паролей.

Что нужно
• Windows 10 или 11 (64-битная) и Chrome 120 или новее.
• Программа-компаньон Waysplit для Windows. Расширение само не подключается к серверам — это делает компаньон с открытыми ядрами sing-box и Xray. Установка: скачать архив, распаковать и запустить «Установить.cmd»; права администратора не нужны, ядра уже в архиве. Ссылка и шаги — на странице «Начало работы», которая открывается после установки расширения.
• Свои серверы: ссылки или адрес подписки от вашего VPN-провайдера. Waysplit серверов не предоставляет.

Конфиденциальность
Серверы, подписки, правила и настройки хранятся только на вашем компьютере. У Waysplit нет своего сервера, учётных записей, аналитики и рекламы, разработчик не получает никаких ваших данных. Подробно — в политике конфиденциальности.

Открытый исходный код (лицензия Apache 2.0), вопросы и сообщения об ошибках: https://github.com/jacks553/waysplit
```

Почему так: описание начинается с того, что делает расширение (так советует best_listing); требования — компаньон, Windows, свои серверы — сказаны прямо (SPEC-STORE.md, подводные камни: проверяющий без компаньона и серверов не подключится); нет превосходных степеней, чужих брендов и списков ключевых слов (правило Keyword Spam). Упомянуты только протоколы и ядра, на которых всё работает (честное указание чужого кода, не реклама).
