# Карточка Waysplit в Chrome Web Store

Тексты для вкладки «Описание в магазине» (Store listing). Сверено с документацией магазина 8 ноября 2026 г. (developer.chrome.com/docs/webstore: cws-dashboard-listing, best_listing, images, program-policies).

Имя на GitHub в ссылках — `jacks553`.

## Название

**Waysplit** — берётся из manifest.json (поле `name`); в панели его не поменять, только новой версией.

Проверка названия (8 ноября 2026 г.): поиск «Waysplit» в Chrome Web Store ничего не находит, поиск в интернете — тоже, продукта с таким именем нет. Похожие по написанию — WSplit (таймер для спидранов) и WavSplit / waveSplit (нарезка звуковых файлов): другие области, путаницы не будет.

## Краткое описание

Берётся из `extension/_locales/ru/messages.json` (с версии 1.2.0; не длиннее 132 символов; в панели не меняется). Сейчас — 128 символов:

> VPN для Chrome через ваши серверы VLESS, XHTTP и Hysteria2: часть сайтов через VPN, часть напрямую. Нужен компаньон для Windows.

## Подробное описание

Вставить в поле «Описание» (Description) целиком:

```text
Waysplit работает как VPN только для браузера Chrome, через ваши собственные серверы. Нужные сайты идут через VPN, остальные без VPN. Другие программы на компьютере VPN не затрагивает.

Что умеет
• Серверы VLESS с Reality, Vision и XHTTP и серверы Hysteria2. Они добавляются по ссылкам vless:// и hysteria2:// или по подписке вашего провайдера.
• Правила для сайтов: "всегда через VPN" и "всегда без VPN". Через VPN сайт идёт через текущий или выбранный сервер. Правило действует на все поддомены, можно задать целую доменную зону.
• Домены сайта: вместе с сайтом по его правилу идут домены, с которых он берёт видео, картинки и скрипты. Например, у видеосайта через VPN идут и страница, и само видео с картинками. Список доменов виден у правила, любой можно убрать.
• "Российские сайты без VPN": флажок на главной. Когда он стоит, сайты в зонах .ru, .рф, .su и российские сервисы на других доменах открываются без VPN, даже если VPN включён. Ваши правила важнее.
• Правила могут работать и при выключенном VPN: через VPN идут только выбранные сайты.
• Всё управление находится прямо в окне расширения, на вкладках "Главная", "Серверы", "Правила", "Настройки". Для открытого сайта на главной есть кнопки "Через VPN" и "Без VPN" и выбор сервера.
• Два вида окна: новый, похожий на кнопочный телефон, и классический. Вид и тема выбираются в меню, которое открывается нажатием на название Waysplit в шапке окна.
• Выбор сервера в один щелчок, избранные серверы, проверка пинга, выбор сервера с наименьшей задержкой.
• Защита от утечек: пока VPN включён, WebRTC не выдаёт ваш настоящий IP-адрес. Если сервер недоступен, сайт не откроется без VPN. Это поведение можно изменить в настройках.
• Подписки обновляются сами. Видны трафик, срок действия и сообщения провайдера.
• Диагностика и отчёт для отладки без ключей и паролей.
• Интерфейс на русском и английском.

Что нужно
• 64-битная Windows 10 или 11 и Chrome 120 или новее.
• Программа-компаньон Waysplit для Windows. Расширение само не подключается к серверам, это делает компаньон с открытыми ядрами sing-box и Xray. Чтобы установить его, скачайте архив, распакуйте и запустите "Установить.cmd". Права администратора не нужны, ядра уже в архиве. Ссылка и шаги есть на странице "Начало работы", которая открывается после установки расширения.
• Свои серверы: ссылки или адрес подписки от вашего VPN-провайдера. Waysplit серверов не предоставляет.

Конфиденциальность
Серверы, подписки, правила и настройки хранятся только на вашем компьютере. У Waysplit нет своего сервера, учётных записей, аналитики и рекламы, разработчик не получает никаких ваших данных. Разрешение видеть, к каким доменам обращаются вкладки, необязательное. Waysplit спрашивает его один раз, от него можно отказаться. Оно нужно только для доменов сайта: чтобы добавлять их автоматически и показывать список доменов вкладки. Подробности есть в политике конфиденциальности.

Открытый исходный код, лицензия Apache 2.0. Вопросы и сообщения об ошибках: https://github.com/jacks553/waysplit
```

Почему так: описание начинается с того, что делает расширение (так советует best_listing); требования — компаньон, Windows, свои серверы — сказаны прямо (SPEC-STORE.md, подводные камни: проверяющий без компаньона и серверов не подключится); нет превосходных степеней, чужих брендов и списков ключевых слов (правило Keyword Spam). Упомянуты только протоколы и ядра, на которых всё работает (честное указание чужого кода, не реклама); «домены сайта» объяснены на общем примере — видеосайт, без названий чужих сервисов. Разрешение из версии 1.1.0 названо прямо: необязательное, спрашивается один раз, можно отказаться.
